## 📌 Projects

### 🔹 Credit Risk Default Prediction
**Tools:** Python, Pandas, Scikit-learn  
**Models:** Logistic Regression, Random Forest, SVM  

**Objective:**  
Build a predictive credit risk model to estimate loan default probability and support portfolio-level risk segmentation.

**Approach:**  
- Performed data preprocessing and EDA to identify key financial risk indicators  
- Built and compared multiple ML models  
- Tuned hyperparameters using GridSearchCV and standardized features  

**Outcome:**  
- Random Forest achieved ~90% accuracy with high recall for high-risk customers  
- Identified major risk drivers such as income stability and credit history  
- Developed a scoring framework to classify customers into Low, Medium, and High Risk

### 🔹 Customer Churn Prediction (Machine Learning)
**Tools:** Python, Pandas, Scikit-learn, TensorFlow  

**Objective:**  
Predict customer churn and derive insights useful for retention strategies and portfolio analytics.

**Approach:**

- Conducted EDA to identify churn drivers across services

**Outcome:**  
- Evaluated models using Precision, Recall, F1-score, and ROC-AUC  
- Identified key churn predictors
